文档 Echo回应 用户协议及隐私政策（Android 版）

更新日期：2026 年 11 月 11 日

生效日期：2026 年 11 月 11 日

本应用名为“Echo回应”，由上海应用技术大学回应工作室团队（大学生大创实践项目）负责后续运营与维护，所有成员均为本校学生。Echo回应的服务主要基于上海应用技术大学教务系统及相关校内服务，由本团队负责技术支持与日常运维。使用本软件即代表你理解并同意以下条款：

Echo回应不是上海应用技术大学官方应用，也不代表学校提供官方服务。

Echo回应由学生团队独立开发和维护。学校数据、通知与办事结果请以学校官方系统为准。

一、服务说明

Echo回应提供课表、成绩与绩点、考试安排、一卡通余额与流水、宿舍电费、图书馆借阅、第二课堂、OA 公告与校园新闻等校园信息展示功能，以及校历、书单、新生、教学计划、校园地图、校园导航、校园问答、学校电话与反馈等附加功能。课表、成绩、考试、一卡通、电费、图书馆、第二课堂、OA、新闻等学校数据有两种获取方式：由设备直连学校系统，或经 Echo 服务获取；书单、新生、教学计划等附加服务由 Echo 提供；校历、校园地图、学校电话、反馈等由 Echo 或内置数据提供。Echo回应由学生团队独立开发和维护，不是学校官方应用，也不代表学校提供官方服务。学校系统由学校提供并运营，Echo回应不对其可用性、稳定性或数据准确性作担保；如遇学校系统问题，请联系学校相关部门。如你未满 18 周岁，请在监护人指导下使用。

二、账号与登录

你使用自己的学校账号登录，账号由学校统一身份认证系统校验。Echo回应不建立独立账号体系，也不会把学号、密码或登录状态提供给无关第三方。账号密码仅用于登录学校系统、建立 Echo 会话和维持登录状态，不用于其他目的。你授权本应用以用户代理身份使用你的身份信息访问学校站点，仅在您主动操作时向学校系统或 Echo 服务提交请求。选择本地直连时，登录会先建立学校会话，再建立附加功能所需的 Echo 会话；学校会话失败会提示你重新登录，Echo 会话失败不影响学校数据使用，但附加功能可能暂时不可用。会话失效时，应用会在本机使用已保存的凭据尝试重新登录；失败时会提示你重新输入。游客可以不登录进入，但只能使用 Echo 侧的公开与附加功能；学校个人数据需要登录学校账号后使用。

三、数据如何流动

学校数据的流向取决于你选择的来源。本地直连模式下，课表、成绩、考试、一卡通、电费、图书馆、第二课堂、OA、新闻等查询由本机直接发往学校统一身份认证、教务、一卡通、学工与融合门户等系统，Echo 服务不参与这些查询，也不会收到对应的账号 Cookie 与查询结果；为建立附加功能所需的 Echo 会话，登录时仍会向 Echo 登录服务提交你的学校账号与密码。学校数据经 Echo 模式下，上述学校数据的查询请求由 Echo 后端代为发往学校系统，账号凭据、会话信息与查询结果会经 Echo 服务处理并返回。书单、新生、教学计划等附加服务，以及校历、校园地图、学校电话、反馈等，由 Echo 提供；选择本地直连不会改变这部分请求的走向。校园导航与校园问答是内嵌的 Echo 服务页面：进入校园导航时，应用把 Echo 登录态写入该站点的 WebView 本地存储，地图、路线与共建请求直达 campus.echo-sit.com；进入校园问答时，应用用 Echo 登录态向 Bot 服务换取独立会话，不把学校密码交给 Bot，聊天与知识库请求直达 bot.echo-sit.com，聊天内容会由 Bot 服务按现有链路发送给所接入的模型与向量服务；自动登录不可用时，页面会显示 Bot 自己的登录入口，若你选择手动登录，学校账号密码会提交给 Bot 服务用于建立其会话。仅在你明确参与的诊断测试中，脱敏后的运行日志会上传到 Echo 日志服务用于排查，不包含请求体、Cookie、密码或 token；学号仅用于区分用户。

四、本地保存哪些数据

以下数据保存在应用私有目录，仅用于自动登录、离线查看和外观偏好：

  • 登录凭据：本地直连的学校凭据（学号、密码）与学校 Cookie 使用 Android 系统密钥库的 AES-256-GCM 加密保存；Echo 会话的登录凭证与 Echo 侧 Cookie 另行保存在应用私有目录。退出登录会同时删除两套凭证。
  • 内嵌网页会话：校园导航与校园问答使用 WebView 的本地存储保存对应服务的登录态；校园问答的 access token 另有加密副本，refresh token 保存在 WebView 的 HttpOnly Cookie 中。退出登录会清理 WebView 的 Cookie、本地存储与 Bot token。
  • 学校数据缓存：本地直连与经 Echo 获取的课表、成绩、GPA、考试、一卡通等结果都可能缓存在本机 Room 数据库，按账号隔离；清理缓存或退出登录即删除。
  • 课表主题、背景图片与外观偏好：按账号隔离保存；移除背景或恢复默认外观即删除当前账号的图片。
  • 电费宿舍信息：从学工系统读取的楼栋与房间号只在本次查询中使用，不写入磁盘。
  • 日志：默认只保存在本机且已脱敏；诊断测试版开启远程上报时，仅上传阶段、耗时、错误类型等脱敏字段，不上传请求体、Cookie、密码或 token。

五、系统权限

应用只申请功能所需的最小权限：

  • 网络：访问学校系统、Echo 服务与公开配置，必需。
  • 照片：选择课表背景时调用系统照片选择器，只读取你选中的图片，不申请相册访问权限。
  • 定位：仅在校园导航中请求，用于在地图上显示你的位置与规划路线；拒绝后仍可浏览地图。
  • 通讯录、短信、麦克风、相机：不使用。

六、共享与第三方

Echo回应不出售、出租或交易你的个人信息，也不会把数据用于广告、画像或跨应用追踪。应用不接入广告或统计 SDK。除学校系统与 Echo 服务外，我们不会向其他第三方提供你的账号数据；Echo 服务由学生团队运营，用于提供学校数据的 Echo 来源与附加功能，其处理范围见本政策第三节。为实现功能使用的开源组件均在本机运行，不会额外收集你的账号数据。

七、数据安全

账号密码与 Cookie 由系统密钥库加密保存；与学校系统、Echo 服务之间使用 HTTPS；日志已脱敏；应用关闭了系统自动备份。本地直连的学校数据在本机处理，请保护好设备锁屏与系统账号；经 Echo 服务处理的数据由 Echo 服务按相应安全措施保护。若发现安全问题，可通过下方反馈渠道联系。

八、安全事件响应

如发生个人信息泄露、丢失或被未经授权访问等安全事件，我们会及时评估影响，通过应用内提示或反馈渠道告知你，并按法律法规要求处理；同时排查原因、修复问题，尽量减少损失。本地直连的学校数据事件范围通常限于本机；涉及 Echo 服务或学校系统的事件，我们会与相应服务方协同排查，也请你同时联系学校相关部门。

九、你的权利

你可以随时管理自己的数据：

  • 查看：在课表、成绩、考试、一卡通等页面查看本机缓存与学校返回的数据；附加功能的数据由 Echo 提供。
  • 更正：学校数据以学校系统为准；如发现错误，请先在学校系统核对。
  • 删除：设置页可清理各类缓存；退出登录会删除账号、两套会话凭证与业务缓存；卸载应用会删除应用私有数据。Echo 服务侧的数据可联系反馈群申请处理。
  • 撤回同意：停止使用并退出登录即停止后续数据处理；已缓存数据可按上述方式删除。

十、使用规范

你应使用本人账号，遵守法律法规与学校规章制度，不得利用本应用批量抓取、恶意请求、绕过访问控制、查询他人信息或干扰学校系统运行。电费查询仅限本人寝室；GPA 计算器结果仅供参考，不作为学校证明。团队有权对异常使用行为进行调查，并保留暂停服务、记录相关信息及移交学校有关部门处理的权利。

十一、服务边界与免责

Echo回应不是学校官方应用。学校系统与 Echo 服务可能维护、调整或暂停服务，数据准确性与可用性以学校和服务提供方为准。因学校系统维护、网络异常、设备故障或不可抗力导致的中断，我们会尽力提示并展示已有缓存，但不承担由此产生的间接损失。

十二、政策更新

政策更新时，我们会修改本页面的更新日期，并在应用内以适当方式提示。若更新涉及你权利的重要变化，我们会要求你重新阅读并同意；未完成重新同意前，相关功能可能暂停。如不同意更新后的内容，请停止使用并退出登录。

十三、联系我们

如对用户协议或隐私政策有疑问、意见或删除请求，可通过以下方式联系学生团队：
